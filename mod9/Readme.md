## Module 9 - Assignment

### isChar:
- isChar defines 2 methods for checking if an input value is a charecter. The first checks using logical operations and the second uses conditional control flow.

### Grade:
- This program converts a numerical grade into a letter grade

### findLargest:
- This program finds the largest of 3 values.

Makefile:
- assemble and link isChar.s
- assemble and link Grade.s
- assemble and link findLargest.s

### Usage:
```bash
make
./isChar
./Grade
./findLargest
```
